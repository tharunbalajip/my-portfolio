🤖 CARAT AI Assistant

CARAT is a Python-based personal AI voice assistant project created to interact with the user and respond to voice commands.

🤖 Project Type

Personal AI Voice Assistant

💻 Technology

Python

🎯 Objective

Create a personal assistant that can interact with the user through voice.

✨ Project Features

  • Python-based AI assistant
  • Voice interaction
  • Text-to-speech functionality
  • Speech recognition support
  • Google web search
  • Voice-based calculator
  • Windows application control
  • Personal notes system
  • Command-based interaction

▶️ How to Run

CARAT can be developed and run using Python on a Windows computer.

Install the required Python packages and execute the project using the Python interpreter.

The complete source code and installation instructions are available on GitHub.
