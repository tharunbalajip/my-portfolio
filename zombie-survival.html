🧟 Zombie Survival

Zombie Survival is a survival game developed using Python and Pygame. The player must survive against waves of zombies and stay alive for as long as possible.

🎮 Game Type

Survival / Action Game

💻 Technology

Python + Pygame

🎯 Objective

Survive against the zombies and achieve the highest possible score.

✨ Game Features

  • Player movement
  • Zombie enemies
  • Shooting system
  • Survival gameplay
  • Score system
  • Game over system
  • Restart option

▶️ How to Run

The game can be run on a computer using Python and the Pygame library.

Open the project folder in VS Code and run the Python game file.
